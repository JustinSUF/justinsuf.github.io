# welcome

this is the spot where i'll keep notes, devlogs, and whatever else feels like writing down.

## what goes here

- project updates (quadra isles dev notes, etc.)
- random thoughts
- documentation for things i build

## how it works

each post is just a `.md` file in the `posts/` folder. add an entry to `posts/posts.json` with the slug, title, date, and summary — it shows up in the list automatically.

```js
{
  "slug": "my-post",
  "title": "my post",
  "date": "2025-05-19",
  "summary": "short blurb"
}
```

that's it.
